# Device protocols

[Documentation index](../index.md) · [API overview](../api/overview.md)

Device pages describe the feeder's wire format and supported virtual USB
behaviour. Use the matching server/client contract; do not treat one device's
binary input as interchangeable with another's.

- [Xbox 360](xbox360.md)
- [DualShock 4](dualshock4.md)
- [DualSense and DualSense Edge](dualsense.md)
- [Switch 2 Pro](ns2pro.md)
- [Keyboard](keyboard.md)
- [Mouse](mouse.md)
- [Xbox One/Series source specification](https://github.com/hbashton/VIIPER/blob/main/device/xboxone/SPEC.md)

Audio, adaptive triggers, motion and microphone behaviour depend on the device
type and matching feeder. For DS4Windows, use the backend bundled with the app.
